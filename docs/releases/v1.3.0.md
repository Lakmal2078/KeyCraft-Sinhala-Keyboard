# KeyCraft Sinhala Keyboard v1.3.0

## Highlights

- Added atomic composition and no-suggestion input modes.
- Improved Sinhala phonetic typing, transliteration, and input recovery.
- Added vibrant keyboard themes and refined theme selection.
- Improved clipboard history, quick paste interactions, and touch handling.
- Improved keyboard accessibility, candidate visibility, and contextual toolbar behavior.
- Refined Termux coding layout spacing and key alignment.
- Added selective Android backup: only keyboard preferences are included in device backup.
- Updated project website, screenshots, and social sharing assets.

## Included improvements

- More reliable Sinhala composition and suggestion behavior across editor states.
- Better keyboard touch targets, hit-testing, and accessibility regression coverage.
- Improved clipboard pane layout and interaction consistency.
- More balanced Termux keyboard rows and modifier-key placement.
- Updated UI regression and Sinhala integration tests.
