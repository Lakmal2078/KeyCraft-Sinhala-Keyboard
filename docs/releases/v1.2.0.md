# KeyCraft Sinhala Keyboard v1.2.0

## Highlights

- Improved Sinhala Singlish transliteration, input handling, and grapheme-cluster deletion.
- Improved keyboard responsiveness and suggestion handling performance.
- Improved keyboard touch targets, hit-testing, and accessibility.
- Fixed keyboard sizing, clipboard pane layout, and vertical keyboard touch handling.
- Unified the contextual toolbar and refined the emoji pane layout.
- Fixed Termux layout registration and keyboard-row alignment.
- Updated the bilingual project website and F-Droid release metadata.

## Included improvements

- More reliable Sinhala typing and transliteration edge-case handling.
- Better interaction behavior around keyboard bounds and touch targets.
- More consistent layout behavior across keyboard orientations and Termux.
- Updated UI regression and Sinhala integration tests.
