## KeyCraft Sinhala Keyboard v1.4.1

### Fixed
- Fixed Singlish live composing backspace behaviour.
- Typing `amma` and pressing backspace once now correctly produces `අම්ම` instead of `අම්ම්`.
- Improved synchronization between the Singlish phonetic buffer, Sinhala composing text, cursor position, and suggestions.
- Improved deletion handling for Sinhala vowel signs, virama, and conjunct consonants.
- Preserved direct Sinhala typing and literal Singlish behaviour.

### Installation
1. Download the APK below.
2. Open it on your Android device.
3. Allow installation if prompted.
4. Install or upgrade KeyCraft Sinhala Keyboard.
5. Enable and select KeyCraft as the active keyboard.

### Privacy
The keyboard works offline. Personal learned words remain on your device.
