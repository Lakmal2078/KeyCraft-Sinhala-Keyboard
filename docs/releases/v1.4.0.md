# KeyCraft Sinhala Keyboard v1.4.0

## Highlights

- Improved direct Sinhala typing, including vowel-sign replacement, virama and conjunct handling, and backspace editing.
- Refined Singlish transliteration and candidate suggestions, including the option to retain literal Latin spelling until a candidate is selected.
- Improved Sinhala word suggestions and local learning behavior.
- Improved keyboard layout, accessibility and touch handling.
- Strengthened optional dictionary download verification and translation shortcut safeguards.

## Privacy

Core keyboard input and bundled suggestions work offline. Optional dictionary downloads require internet access; choosing external translation can open another app or service and may share text the user explicitly selects.

## Installation

Download the signed APK asset and install it on Android. If upgrading from v1.3.0, Android should accept an in-place update because the release signing certificate is unchanged.

## Verification

Release build: Android SDK 36, versionName 1.4.0, versionCode 6. Debug unit tests, Sinhala corpus, lint and the connected-device checks are part of the release validation. See repository CI for additional coverage.

## Known limitations

Editing behavior can depend on the host application's InputConnection implementation. Optional downloaded dictionaries are not required for offline core typing.
