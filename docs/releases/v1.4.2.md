## KeyCraft Sinhala Keyboard v1.4.2

- Existing pinned clipboard entries migrate to encrypted storage on first access. New pins use AES-GCM with a key managed by Android Keystore.
- Keyboard settings, learned words, and clipboard data are excluded from Android cloud backup and device-to-device transfer.
- Sinhala joiner gestures require a consonant followed by a virama, preventing invisible joiners in an empty editor.
- Requires Android 10 (API 29) or later. Devices on Android 9 and earlier cannot install this update.

### Verification

The release candidate checklist covers the Sinhala corpus and editing tests, Android device tests, and production APK signature and checksum. Record candidate-specific test results before publishing.
