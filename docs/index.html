KeyCraft – Sinhala Keyboard for Android

Type Sinhala in Singlish and get instant Sinhala text. Free and open source.

Download KeyCraft v1.1.0 (APK)

Features

  • Singlish to Sinhala: type amma and get අම්මා.
  • Swipe typing with extra characters from key corners.
  • Word suggestions and spelling help.
  • Customizable layouts, themes, key shapes and fonts.
  • Productivity tools: clipboard history, text shortcuts and a quick calculator.

Installation

  1. Download the APK from the official release page.
  2. Allow installation from that source when Android asks.
  3. Open KeyCraft and follow the steps to enable it and set it as your default keyboard.

Settings menu names may differ by Android version and phone brand.
